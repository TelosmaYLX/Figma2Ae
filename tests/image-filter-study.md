# Figma 图片调色在 After Effects 中的还原验证

2026-11-20，在 Figma 桌面端和 After Effects 26.0x67 中实测。AE 工程为 8 bpc、工作空间 None。输入为 sRGB PNG。原始图片填充的七个值依次为曝光 −0.17、对比度 +0.05、饱和度 +0.18、白平衡 −0.26、着色 +0.21、高光 −0.21、阴影 +0.13。

## 结果

固定调色可以采样成 3D LUT，加在 AE 中的原图上。红车原尺寸 1127 × 677 上，64³ LUT 的不透明像素平均 RGB 通道误差为 0.18，99% 的通道误差在 1 个色阶以内。七个参数可以作为 AE 滑杆驱动原生效果并打关键帧。本次近似方法在重新调色时会产生可见偏差。

| 实验 | 平均 RGB 通道误差 | 99 分位 | 最大 RGB 通道误差 | 最大 Alpha 误差 |
| --- | ---: | ---: | ---: | ---: |
| 七项直接换算到 Lumetri，原尺寸不透明车身 | 5.10 | 25 | 60 | 0 |
| 64³ LUT，原尺寸不透明车身 | 0.18 | 1 | 6 | 0 |
| 64³ LUT，5,897 个半透明边缘像素，黑底合成 | 0.11 | 1 | 2 | 0 |
| 64³ LUT，独立色卡的 16,384 个留出像素 | 0.14 | 1 | 9 | 0 |
| 原图在 AE 缩放至设计稿大小，与所选图层的 570 × 342 导出对比 | 0.72 | 5 | 23 | 21 |

色阶以 0–255 计。RGB 计算每个通道的绝对差。透明图像按相同预乘方式换算至黑底，主体统计排除全透明像素，Alpha 另行比较。设计稿大小一行同时包含缩放、边缘覆盖和颜色的误差。

## 比较方法

- Figma 原生渲染分别覆盖七个滑杆的 −1、−0.5、+0.5、+1、全零、红车设置和另一组组合设置。直接映射使用 Lumetri 曝光 ±5 档、其他滑杆 ±100，饱和度以 100 为中性。另以 4,096 个训练像素，对七个 Lumetri 参数各扫描 101 档，也试了独立曝光度、亮度和对比度、色相/饱和度、阴影/高光。这些设置均未建立可在全范围复用的等价关系。
- 对 64³ 个已知输入颜色应用完整的 Figma 调色，再将 Figma 渲染结果按红色最快变化的顺序写入 .cube。8 位 PNG 中采样点位于整数色阶，写表时重采样到等距网格。AE 使用原生“应用颜色 LUT”。
- 追加的 4096 × 4096 色卡覆盖全部 16,777,216 个 8 位 RGB 值。全零色卡复核与输入一致，重复采集的调色色卡也一致。用完整表离线查色，红车的 576,489 个不透明像素和独立测试图的 32,833 个不透明像素都与 Figma 逐通道相同。本机 AE 使用该 256³ .cube 的尝试输出了原图，工程采用已在 AE 验证的 64³ 表。
- 现行 F2A 导出这张图层所得的 570 × 342 PNG，与该图层的 Figma 导出逐像素一致。现有回归用例还覆盖 Frame 背景填充、保留子层与边框、独立遮罩及关闭效果栅格化时的提示。

## 七个可编辑滑杆

样例工程的“红车 · 七项可调”合成提供七个 AE 原生滑杆，读数为 Figma API 数值的 100 倍。起始值为 −17、5、18、−26、21、−21、13。以红车固定 LUT 还原起始外观，再根据滑杆相对起始值的变化驱动 Lumetri。原值附近使用实测校准，远离原值时使用独立滑杆扫描得到的分段近似。七项全零回到原图。该工程可以离线运行。

下表以红车原尺寸所有可见像素统计。每次只改一项，其余六项保留设计值。每个数字都是一次实际 AE 渲染与相同设置的 Figma 渲染之间的平均 RGB 通道误差。

| 滑杆 | 在原值上减 20 | 在原值上加 20 |
| --- | ---: | ---: |
| 曝光 | 1.06 | 5.44 |
| 对比度 | 1.50 | 1.35 |
| 饱和度 | 5.37 | 0.70 |
| 白平衡 | 3.24 | 2.45 |
| 着色 | 2.73 | 2.11 |
| 高光 | 1.06 | 1.17 |
| 阴影 | 1.11 | 1.05 |

七项同时在原值上加 [9, −10, −15, 11, −7, 12, 8] 时，平均误差为 6.16、99 分位为 47。换到 [23, −11, 42, 21, −12, 34, −19] 时分别为 15.05、77。曝光从 −17 动画到 +3，AE 中点帧与手动设为 −7 的帧完全一致。重新打开 AEP 后，两套合成的起始帧与保存前逐像素相同。

以上结果适用于本次的 8 位 PNG、色彩设置和 AE 版本。P3、线性工作空间、HDR 与多重填充的逐层调色仍需另外验证。

## 复现固定 LUT

在当前源码版 F2A 中选中只有一项可见图片填充的图层。安装仓库 MCP 的 Node 依赖，Python 环境需有 NumPy 和 Pillow。运行下列命令，输出到一个新的 .cube 文件，再在 AE 的原图层上使用“应用颜色 LUT”。

```powershell
node tests/sample-image-filter-lut.cjs red-car.cube
```

脚本创建一张临时色卡，验证无调色读数，复制所选图片填充的 filters，再采样并移除临时图层。可传入第二个参数指定 F2A 文档连接 ID。本次重新运行得到的 262,144 行数值与样例工程使用的 LUT 完全一致。
