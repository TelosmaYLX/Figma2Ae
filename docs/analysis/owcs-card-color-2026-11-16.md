# OWCS 卡面颜色偏差分析

分析日期：2026-11-16。仓库基线：`7f698d6`。

## 结论

主要问题是穿透混合链被预合成和轨道遮罩隔开。两张建筑图片的加深模式没有对外层蓝色背景运算，导致建筑变成灰白色。仅打开所有塌陷变换不能解决这份工程中的轨道遮罩隔离。另有一处独立错误：两张图片填充的 80% 透明度在原图素材通道中丢失，写入 AEP 后为 100%。

用户指出的两点与本次检查一致：

1. 内部图片到外层底图之间的穿透祖先链需要贯通，当前工程没有贯通。
2. 当前结构把轨道遮罩施加在包含内部混合层的预合成上，使开启塌陷后的结果仍然不能按原稿与外部底图混合。

这份记录只分析当前样例，不把所有轨道遮罩、混合模式或 AE 工程概括为相同表现。

## 修复应满足的条件

1. 保持原稿的穿透/隔离语义；需要外部底图的混合层，必须能与正确底图完成运算。
2. 蒙版固定图片外观后，将原混合模式应用在蒙版结果的外层；不要把需要外部底图的加深层锁在隔离预合成内。需要保持多个子层编辑能力时，应另外设计蒙版结构并做真实 AE 对照。
3. 图片填充透明度必须保留；只有单一图片填充、没有其他绘制时，可按正确的透明度语义传递，而不必因此合并整个父组。
4. 合并开关只能在依赖底图完整的范围内宣称完成；白框已经合并不等于建筑加深已完成合并。
