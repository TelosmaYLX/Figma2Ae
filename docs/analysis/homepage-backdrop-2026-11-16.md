## 根因与 Figma 复现

`_exportRasterPng` 为小数边界创建对齐像素网格的画布，将节点复制到该画布后导出。旧画布在页面最上层。节点带背景模糊时，画布下方已经包含原按钮的上层文字，导致这份文字进入背景采样。

通过 F2A MCP 创建完整首页的临时副本，保持相同位置和图层内容，对同一块底框进行对照：

1. Figma 直接导出底框：没有文字。
2. 将底框复制到页面顶层的 364×66 透明画布：出现模糊文字，与用户原导出 `0004.png` 的 RGBA 最大差为 0。
3. 将同一画布移回按钮内部，插在源底框之前绘制：文字消失，背景模糊和边框仍在；与 Figma 直接导出底框的 RGBA 最大差为 0。

实验使用 MCP 的临时透明填充画布；其 alpha 为 1e-9，像素对照已确认没有改变结果。临时副本和画布均已删除，原图层及用户选区未改动。

## 修改

`figma-plugin/code.js` 新增 `_rasterNeedsBackdrop`，识别当前节点及可见子内容中的背景模糊/玻璃效果。需要小数边界补边时，将切图画布插入导出副本内、紧靠源节点之前的绘制位置，并通过父级逆变换保持世界坐标。这样既不会采样上方文字，也不会把源底框自身再次当作背景。

自动布局中的临时画布采用绝对定位。画布仍按选区像素网格对齐，图形小数坐标、倍率及透明补边保持原规则。`tests/raster-backdrop.cjs` 检查叶层、整组图片、自动布局、独立文字、同层绘制顺序以及 101×39 的小数边界补边结果。
