# F2A AEP 导出兼容性与合并判定矩阵

本文档总结自 F2A 实际采集与写入源码（`figma-plugin/code.js`、`host/figma/svgParser.js`、`scripts/aep/writer.py`、`scripts/aep/packet.cjs`），用于指导 Figma 图层整理时“**尽可能保留独立图层**”与“**必要时做最小范围合并**”的精确判断。

---

## 1. F2A `.aep` 的核心处理机制

1. **默认节点树模式（`useNodes: true`）+ 保留分组层级（`organize: true`）**：
   - 每个普通叶子节点（矢量/矩形/椭圆/布尔结果/图片/文字）尽量映射为 1 个 AE 原生图层；
   - 每个保留的容器（`GROUP` / `FRAME` / `COMPONENT` / `INSTANCE`）映射为 1 个 AE 预合成（Precomp），容器的 `opacity`、`blendMode`、`clipsContent` 挂在预合成层上；
   - **纯文字透明容器豁免（`_isPureTextContainer`）**：若容器不裁剪、无填充/描边/效果、透明度 100%、非混合隔离、且内部只有 `TEXT` 节点（无绘制层和蒙版），F2A 会自动跳过不建冗余预合成；
   - **实例全部分离整理**：虽然 F2A 导出时会在临时副本上分离实例，但 Figma 中组件实例内部是只读的（无法改名、拆空壳、调 Z 序或抽离底框）。为保证动效师在原稿就能看到完整可编辑层级并自由修改内部结构，本 Skill 在整理阶段会**自动将目标范围内的全部 `INSTANCE` 由外向内递归分离为普通 Frame**（若根选区自身即为实例，则用返回的新 Frame ID 续接后续步骤）。
2. **`*` 前缀强制栅格化规则（`_isForcedRaster`）**：
   - 任何名称以 `*` 开头的图层，F2A 会将其连同所有子图层整体导出为一张 PNG，内部文字、矢量、遮罩全部合并。
   - **误用后果**：非合并意图的图层名以 `*` 开头会直接丢失所有可动画子层。
3. **默认高级选项假设（与 `figma-plugin/ui.html` 默认值一致）**：
   - `保留分组层级`：开
   - `保留画框裁剪`：开
   - `忽略隐藏图层`：开
   - `文字导出方式`：默认「矢量形状（无需字体）」（或动效师按需切换「可编辑文字」）
   - `图片蒙版`：默认「原图 + 独立蒙版」
   - `允许自动转为图片` 5 项（效果、特殊填充、图片裁剪、复杂蒙版、布尔结果）及 `合并混合模式与底图`：默认全部开启

## 2. 完整兼容性与整理策略矩阵

| Figma 特性 / 图层情况 | F2A 导出 `.aep` 实际行为 | 整理建议（保留 vs 合并） |
| --- | --- | --- |
| `RECTANGLE` / `ELLIPSE`（非圆环/弧） | 轴对齐且统一圆角时转为 AE 参数化形状（可调 Size/Roundness）；旋转/混合圆角保留矢量路径 | **坚决保留**，不合并 |
| `VECTOR` / `STAR` / `POLYGON` / 弧形 `ELLIPSE` | 保留可编辑矢量路径（含多区域不同填充自动按 region 拆层） | **保留**；仅对上百个纯静态无动画需求的碎矢量装饰群考虑归组标 `*`（或纯同色矢量 `flatten_nodes`） |
| `BOOLEAN_OPERATION`（有 `fillGeometry`） | 仅导出布尔运算最终矢量结果，忽略内部操作数 | **静态布尔保留即可**；仅当动效师需要对布尔的几个子操作数**分别做动画**时，才拆成独立图层或改用遮罩 |
| `BOOLEAN_OPERATION`（无 `fillGeometry`） | 启用“布尔运算结果”时自动转为单张 PNG | 保留当前节点即可（无需连带合并兄弟层） |
| 纯色填充、线性渐变、径向渐变 | 原生写入 AE 填充 / 渐变填充（`ADBE Vector Graphic - G-Fill`） | **坚决保留** |
| **同一节点 ≥2 个渐变填充** | `svgParser.js` 自动按 paint 拆成多个独立 AE 形状层 | 保留原样或手动拆分（若想自控每个渐变层的名字与动效） |
| 常规纯色描边（Inside/Center/Outside） | 闭合形状通过 AE 图层样式或路径偏移写入；开放路径保留路径描边 | **坚决保留** |
| 虚线描边 / `< 1px` 细描边 | 导出副本上自动轮廓化为填充路径并放入同一 AE 形状组 | **保留原稿不破坏**；极复杂散点笔刷导致导出失败时，先 `outline_stroke` 并核对像素 |
| `GRADIENT_ANGULAR`（角度）/ `GRADIENT_DIAMOND`（菱形）/ `PATTERN` / `VIDEO` / `SHADER` | 无法原生写 AEP；叶子节点自动转单张 PNG，**若挂在容器上则报错要求整容器标 `*`** | 叶子保留独立；**若挂在容器且内含可动子层 → 抽离成独立底层矩形并标 `*`** |
| 普通 `TEXT`（含富文本、行距、字距、倾斜、渐变文字） | 选「矢量形状」导为字形路径；选「可编辑文字」写入原生 TextLayer（渐变文字用 Alpha 遮罩实现） | **坚决保留**；用「可编辑文字」时先查缺字（`get_fonts` / `hasMissingFont`） |
| `TEXT_PATH`（路径文字） | 强制整体栅格化为 PNG | 保留该单层（若静态装饰可随周边装饰归组） |
| 单个 `IMAGE` 填充（`FIT` / `FILL`） | 保留原始图片素材；圆角/椭圆/FILL 加原生 Track Matte | **坚决保留** |
| `IMAGE` 带自定义 `CROP`（含倾斜 `imageTransform`）或调色滤镜（曝光/对比度等） | `AEP` 不支持倾斜裁剪和图像调色滤镜，会固定该图片节点为 PNG | 保持该图片层独立（不要连同上方文字合并）；确认图像无需二次切图 |
| **单节点同时包含 ≥2 个可见 `IMAGE` 填充** | `collectImages` 只读取**第一张**可见 `IMAGE` 并 `break`！其余图片填充会丢失 | **必须处理**：要么拆成多个单图叠加节点并校验像素一致，要么标 `*` 合并该节点 |
| 仅含 `DROP_SHADOW`（投影） | 默认自动通过差值提取纯投影层 `*_投影`，主体/文字保持独立可编辑 | **不要因为有投影而合并图层** |
| `INNER_SHADOW` / `LAYER_BLUR` / `BACKGROUND_BLUR` / `GLASS` / `NOISE` / `TEXTURE` / `SHADER` | AEP 无法原生写，需要栅格化。**加在叶子上仅转该叶子；加在容器上会连带组内子层一起栅格化！** | 叶子保留独立；**容器上有此类效果且内有可动前景 → 尽量抽离底框标 `*`，解放前景**；若确为整体静态氛围块 → 局部组标 `*` |
| 已确认对画面无贡献的效果（`visible:false` 的隐藏效果，或隐藏后像素门禁 `max_abs_diff == 0` 的效果，不限于模糊） | 隐藏效果本来就不参与导出渲染；零贡献效果不产生任何画面 | **整理阶段直接移除该效果条目**（只删效果、不删图层），不占导出负担；有视觉贡献的效果严禁删除或改动参数 |
| 常规纯色 Alpha / Luma 简单矢量蒙版 | 原生转为 AE Track Matte（1 个蒙版遮多个兄弟层时自动生成 `*_内容` 预合成） | **坚决保留**；注意理顺同级叠放次序，避免无意被前置蒙版“误罩” |
| 复杂蒙版（图片蒙版、渐变/带效果蒙版）+ 多个混合模式叠加层 | 若「图片蒙版=原图+独立蒙版」且内层含半透明/重叠混合模式，逐层遮罩易出现 alpha 累积误差或混合上下文隔离 | 纯静态纹理/装饰区建议**归入局部组并标 `*` 合并**；前景主体仍留在外部独立可动 |
| 混合模式（`MULTIPLY` / `SCREEN` / `OVERLAY` / `SOFT_LIGHT` / `COLOR_BURN` / `LINEAR_BURN` 等） | F2A 可传常见混合模式给 AE，也会通过 `collapseForBlends` 开启穿透塌陷，但跨遮罩或 8-bpc 下复杂加深群仍有色偏风险 | **核心可动元素保留混合模式**；**纯静态多张纹理/光影叠加群强烈建议归组标 `*` 合并** |
| `FRAME` 带 `clipsContent: true` | 写入 AE `Clip content` 矩形/圆角 Mask | 无真实溢出的普通容器应关闭 `clipsContent` 或改 `GROUP`；**有裁剪需求必保留**。注意：**混合圆角只取 `topLeftRadius`**，若四角圆角不同且开启裁剪，需改用内部矢量蒙版或局部处理 |

## 3. 动效师视角的“保留 vs 合并”黄金判断法

1. **问自己：动效师会不会对它单独 K 关键帧？**
   - 会（位移、缩放、旋转、透明度、显隐、修路径、换文案、逐个 stagger 入场）→ **绝对不合并**；哪怕它目前在带特效的容器里，也要想办法把特效底板拆出去标 `*`。
   - 不会（例如 8 层叠加只为做出一张金属拉丝/噪点渐变底纹，或背景上的一团复合模糊光斑）→ **果断局部归组标 `*`**，减少 AE 图层负担并确保 100% 色彩还原。
2. **Precomp 深度控制**：
   - 把没有 `opacity` / `blendMode` / `effects` / `clipsContent` / `layoutMode` / `mask` 的多层空套娃拆平；
   - 让 AE 主合成打开后，第一眼就能看到清晰的逻辑板块（背景 / 主视觉 / 文案 / 交互组件 / 前景氛围），而不是一堆无意义的 `Frame 123456`。
3. **混合模式命名标注对照表（命名后置 `（混合模式名）`）**：
   - 仅针对**非默认混合模式**添加（普通叶层默认 `NORMAL` 与容器默认 `PASS_THROUGH` 不加；若同时有填充级混合模式且节点本身为默认，可用 `（填充-柔光）` 或对应模式名标注；若已有该后缀则不重复拼接）：

   | Figma `blendMode` | 中文后缀（全角括号） | 示例 |
   | --- | --- | --- |
   | `DARKEN` | `（变暗）` | `阴影层（变暗）` |
   | `MULTIPLY` | `（正片叠底）` | `纹理1（正片叠底）` |
   | `COLOR_BURN` | `（颜色加深）` | `建筑底纹（颜色加深）` |
   | `LINEAR_BURN` | `（线性加深）` | `压暗层（线性加深）` |
   | `LIGHTEN` | `（变亮）` | `高光1（变亮）` |
   | `SCREEN` | `（滤色）` | `光斑（滤色）` |
   | `COLOR_DODGE` | `（颜色减淡）` | `光晕（颜色减淡）` |
   | `LINEAR_DODGE` | `（线性减淡）` | `流光（线性减淡）` |
   | `OVERLAY` | `（叠加）` | `质感1（叠加）` |
   | `SOFT_LIGHT` | `（柔光）` | `装饰1（柔光）` |
   | `HARD_LIGHT` | `（强光）` | `锐化光效（强光）` |
   | `DIFFERENCE` | `（差值）` | `反相层（差值）` |
   | `EXCLUSION` | `（排除）` | `氛围层（排除）` |
   | `HUE` | `（色相）` | `调色层（色相）` |
   | `SATURATION` | `（饱和度）` | `饱和层（饱和度）` |
   | `COLOR` | `（颜色）` | `着色层（颜色）` |
   | `LUMINOSITY` | `（明度）` | `明度层（明度）` |

4. **零贡献效果先清理，再判断是否合并**：若某个 `BACKGROUND_BLUR` / `INNER_SHADOW` / `LAYER_BLUR` / `DROP_SHADOW` 等只是“挂在那里但没画出来”（已隐藏、被不透明内容完全覆盖、没有可采样的 backdrop、`radius` 为 0 等），先按 `SKILL.md` 策略 D 做隐藏验证并移除效果，再决定是否还需要拆分背景或标 `*`——能少合一层就少合一层；移除必须通过 `max_abs_diff == 0` 门禁，有视觉贡献的效果一律保留。
