# 动画结构规范、跨端适配与制作决策规则

本手册规定了使用 F2A MCP 制作 AE 动画时的**结构铁律**、**Web/Lottie 兼容红线**、**三大制作场景决策树**以及**跨端复用适配公式**。

---

## 1. 核心工程铁律

### 1.1 单元素独立预合成原则（强制）
- **每个需要做动画的独立元素都必须拥有属于自己的单个预合成**，动画关键帧必须施加在**外部父合成中的该元素预合成层**上。
- **严禁直接在裸图层上加动画**：无论是单个文本层、单个形状层（线条、圆点、底框）还是单个图片层，若要对其施加位移/缩放/旋转/透明度动画，**必须先在外层套一层紧凑预合成（tight-bounds precomp）**，再对该预合成层打关键帧。
- **复合元素拆解规则**：以按钮为例，若按钮包含「底框」与「文字」两个图层，且它们需要各自或独立管理动画，则「底框」需有自己的独立预合成、「文字」需有自己的独立预合成，外层再由「按钮」预合成把两者组合起来；整体入场动画打在「按钮」预合成上，底框/文字各自的独立动画打在各自的单元素预合成上。
- **反裁剪收益**：将动画打在外部父合成里的预合成层上，天然避免了在紧贴边界的子合成内部做位移时被子合成边界裁切的问题。
- **豁免说明**：全程完全静止、不参与任何动画的纯背景底图/环境光层（如背景照片、纯色底板）可保持原样，不必无意义嵌套。

### 1.2 关键帧精简铁律（严禁逐帧关键帧）
- **不允许出现逐帧关键帧**（严禁对动画进行逐帧采样/烘焙/每帧打点）。
- 每一个单向运动段（如入场位移、线性淡入、线条生长）只使用 **2 个关键帧**（起点 + 终点）配合精确的 `KeyframeEase` 曲线；需要过冲回弹或两段变速时，最多使用 **3 个关键帧**。
- 所有位置关键帧必须保证**空间切线为 `[0, 0, 0]`**（无意外曲线弧度与位置抖动）。

### 1.3 Web / Lottie / Sprite 导出友好红线（默认遵守）
除非用户明确声明“仅输出视频、无需导出 Web/Lottie”，默认全程遵守以下红线：
- **允许**：纯关键帧驱动的 `Position`、`Scale`、`Rotation`、`Anchor Point`、`Opacity`、图层 `inPoint`/`outPoint`/`startTime`、简单矢量路径遮罩（Mask）与形状路径修剪（Trim Paths）。
- **禁止**：
  - 任何**表达式**（特别注意：`ae_animate` 的 `spring` / `bounce` 风格底层通过表达式实现，Web 模式下**禁止使用**；如需弹性体感，改用 3 个手动贝塞尔关键帧实现）；
  - 第三方插件与重型 AE 内置特效（如复杂粒子、扭曲、表达式驱动模糊等）；
  - 不必要的复杂 Parenting 链路（跨层复合运动优先折算为清晰独立的预合成与关键帧）。

## 2. 动画来源与场景决策树

按以下优先级决定动画方案：

### 场景 A：复用已有参考工程（最高优先级）
当用户指定了参考 `.aep`（例如已有 PC 端工程复用至移动端，或同系列页面复用）：
1. **读取参考动画**：
   - **优先推荐离线只读解析**（不干扰当前 AE 窗口，且兼容高版本 AE 27 工程）：
     ```powershell
     "<F2A_ROOT>\.venv-aep\Scripts\python.exe" "<SKILL_DIR>\scripts\dump_aep_motion.py" "<ref.aep>"
     ```
2. **帧率统一**：
   - 读取参考工程主合成帧率（如 `60fps`），将目标工程全部合成帧率同步为相同帧率（优先导出时设帧率，当前通过 `ae_run_script` 在加动画前批量同步），消除跨帧率半帧问题。
3. **跨端适配规则（如横屏 PC → 竖屏移动端）**：
   - **时间轴与缓动曲线**：默认 **1:1 沿用参考工程**（各模块的先后顺序、错帧节奏、入场时长、Bezier 影响百分比与线性透明度曲线）。
   - **垂直位移距离**：按画幅高度比等比换算并取整：
     $$\Delta y_{\text{target}} = \text{round}\left(\Delta y_{\text{ref}} \times \frac{H_{\text{target}}}{H_{\text{ref}}}\right)$$
   - **水平位移距离与方向转换**：
     - 若布局同构（仍为左右并排非居中），按模块宽度比换算水平位移；
     - **竖屏居中方向转换规则（强制）**：若参考工程为横屏非对称布局（如左车右文、右侧模块水平右→左滑入），而目标移动端为**竖屏居中对称构图**，则将原本的**水平滑入自动改为垂直上浮**（位移幅度参考同屏高比例，如屏高 1.5%–2.5%），使竖屏居中动线自然统一、不左右漂移。
   - **图层层级差异处理**：若某元素在参考工程中嵌套在父预合成内（因而叠加了父+子双重位移与透明度），而在目标稿中与原父组是同级兄弟层，则在目标层上**折算等效复合位移与错帧淡入**，并确保它拥有自己的独立预合成，不强行破坏原始层级或引入多余 Parenting。
   - **参考工程瑕疵自动修正**：
     - 终值存在微小误差（如参考中线条 Scale X 停在 `100.7%`）→ 一律锁定为精确设计稿值（`100%`），保证最终落点 0 偏移；
     - 明显漏改的硬切关键帧（如节点 Opacity 两个关键帧均为 `100→100`）→ 修正为与同组元素一致的 `0→100%` 平滑淡入，并在最终汇报中说明。

### 场景 B：无参考工程，先查 F2A 动效库
当用户未提供参考 `.aep` 时：
1. 调用 `ae_motion_list` 搜索已有动效片段。
2. 若存在匹配该页面气质与图层结构的动效片段，可用 `ae_motion_apply`（`position_anchor: "end"` 保证终帧落位不变）套用，再按需微调错帧与幅度。
3. **入库策略**：默认不自动调用 `ae_motion_save`；仅当用户明确要求“把这套动画存进动效库”时才执行保存。

### 场景 C：无参考、无匹配动效库——从零制作
1. **工具选择**：
   - 简单单层无表达式入场可用 `ae_animate`（仅限 `snappy` / `smooth` / `linear`，禁用 `spring` / `bounce`）、`ae_stagger`、`ae_text_reveal`（仅当 `textMode: "editable"`）；
   - 多模块精确编排、严格时间曲线与精确终值锁定，优先使用 `ae_run_script` / `ae_set_keyframes` 批量写入。
2. **默认精致 UI 动效语汇**（用户未指定具体风格时）：
   - **位移曲线**：`BEZIER`，首帧 `out influence = 33%`（`speed = 0`），末帧 `in influence = 75%`（`speed = 0`）——快起慢收、优雅稳重。
   - **透明度曲线**：`LINEAR` 纯线性 `0% → 100%`，通常比位移更早达到 100%（约为位移时长的 50%–75%），避免半透明拖影。
   - **瀑布错帧节奏**：同组元素间隔 `0.05s`（60fps 下 3 帧），按视觉阅读流（主视觉/顶部标题 → 副标题/信息区 → 列表/时间线 → 底部 CTA 按钮）自上而下或由主到次展开。
   - **位移幅度**：克制精致，常规卡片/标题/按钮垂直位移取画幅高度的 **1.5%–3.5%**；顶部导航自上方落入，主体内容与底部按钮自下方上浮。
   - **工作区（Work Area）**：从 `0s` 开始，在全片最后一个关键帧结束后多留 **0.2s–0.3s** 静止余韵（可凑整至 `0.5s` 档位如 `1.5s`、`2.0s`），方便预览验收与静止帧核对。

## 3. 不同动画类型的落位校验标准

| 动画类型 | 核心校验目标 | 通过标准 |
|---|---|---|
| **入场 / 展示类**（最常见） | 动画结束静止帧（如 Work Area 末尾）vs 导出初始静态帧 | 终帧 Transform 坐标与初始值一致；像素 diff 通过 `verify_resting_frame.py --mode resting`（宽松容差，确认无视觉偏移与裁切） |
| **退场类** | 首帧 vs 初始静态帧；尾帧全清零 | 首帧与初始静态帧一致；尾帧前景完全退出/透明度归 0 |
| **循环类**（呼吸/悬浮/光效） | 首尾帧连续性 + 中间无裁切 | 首帧与尾帧状态平滑衔接（位置/缩放/透明度首尾相等且切线顺滑），任意中间帧无预合成边界截断 |
| **状态切换类** | 切换前状态帧 + 切换后目标状态帧 | 起止两态分别对齐对应设计稿，过渡期间无层级穿帮与闪烁 |
